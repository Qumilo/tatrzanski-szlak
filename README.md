# TatrzańskiSzlak – wypady w Tatry z Zakopanego

Responsywna, statyczna strona internetowa o szlakach tatrzańskich. Zawiera zapisy moich
własnych tras GPS, katalog 16 szlaków, interaktywną mapę z kalkulatorem trasy, listę
ekwipunku, galerię zdjęć, quiz, FAQ oraz formularz opinii.

Projekt wykonany jako praca domowa z tworzenia responsywnych stron internetowych.

## Strona online

https://Qumilo.github.io/tatrzanski-szlak/

## Funkcjonalności (JavaScript)

- rozwijane menu mobilne,
- przełącznik motywu jasnego i ciemnego (zapamiętywany w przeglądarce),
- zegar z informacją o czasie do zmierzchu,
- wyszukiwarka i filtry katalogu szlaków,
- mapa Leaflet z kalkulatorem trasy (dystans, podejścia, czas, punkty GOT),
- lista ekwipunku z dodawaniem własnych pozycji,
- galeria zdjęć z powiększaniem (lightbox, obsługa klawiaturą),
- quiz z losowaniem 8 pytań i wynikiem końcowym,
- rozwijane sekcje FAQ,
- formularz opinii z walidacją danych,
- przycisk powrotu na górę strony.

## Wykorzystane technologie

- HTML5 (znaczniki semantyczne),
- CSS3 (Flexbox, CSS Grid, zmienne CSS, media queries),
- JavaScript (ES6, localStorage),
- Leaflet 1.9.4 (mapa) z kafelkami OpenStreetMap, OpenTopoMap i Waymarked Trails,
- Git i GitHub Pages (publikacja).

## Struktura projektu

```
index.html   – struktura strony
style.css    – style i responsywność
script.js    – interaktywność
images/      – zdjęcia i zrzuty map tras
README.md    – dokumentacja projektu
```
